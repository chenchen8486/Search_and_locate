### 2.1 独立审查后的修正

- 粗层不再按最终 Top-N 截断候选，新增排序反转回归，避免错误候选覆盖原图更优目标。
- 删除原模板尺寸对缩小搜索的误拒，只按实际变换后的模板检查图像和 ROI。
- 负邻近半径返回 `InvalidConfig`。
- CUDA 每个工作线程使用独立流，异步传输和流同步保留，流与显存工作区按线程复用，不使用整设备同步。
- 隐藏对话框自测覆盖控件到配置的映射、显示字段和旧结果清理，模板或 ROI 变化会清理旧结果。
- CPU-only 和独立子进程均验证 `BackendUnavailable`，不会在 GPU 初始化失败后执行 CPU 搜索。

## 4. 500 任务性能

　　固定口径为 500 个任务、197 对独立图像、Release x64、20 线程、完整图、角度 0、尺度 1、金字塔 1、亚像素 4、Top-N 1。预热 5 轮、记录 50 轮。GPU 计时包含数据传输和同步，工作区按线程复用，首次分配在预热中完成，线程退出时的释放不计入单轮批量耗时。2026-11-06 按用户要求将当前基准从 1/8 调整为 1/4，此前的 1/8 结果保留用于观察优化过程，不与新结果混为同一口径。

| 后端 | 整体中位数 | 单任务预处理均值 | 单任务搜索均值 | 单任务整体均值 | 单任务 P99 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CPU | 51.7553 ms | 0.0076559 ms | 1.70333 ms | 1.7127 ms | 7.0523 ms |
| GPU | 39.9098 ms | 0.00666403 ms | 1.30712 ms | 1.31378 ms | 3.2196 ms |

　　1/8 亚像素口径的本轮优化前复测基线为 CPU 160.523 ms、GPU 185.283 ms，等价优化后为 CPU 125.553 ms、GPU 159.672 ms。单线程分解显示，原单任务完整执行平均 1.425069 ms，整图 NCC 为 0.155828 ms，81 次模板平移、同尺寸评分及 OpenCV 复核分别为 0.504920、0.269650、0.430751 ms。主要开销在亚像素精化，OpenCV 内部线程数由 16 改为 1 没有实质改善。

　　当前实现保留全部亚像素候选、双精度评分顺序和 OpenCV 复核，共享样本存储并复用模板与搜索块统计。新增 `SubPixel.PreparedSamples`，逐像素、逐评分比较四档分辨率及非连续图像，CPU-only Release 回归为 40/40，CUDA Release 的 GPU 套件为 12/12，197 对真实数据结果保持原基准。直接改用响应面拟合会使 197 对位置全部出现差异，只复核直接评分最佳项会改变 5 对位置，两种方案均未采纳。

　　按线程复用 CUDA 流与显存工作区后，500 任务由 147.673 ms 降为 59.8326 ms。新增批量响应测试后，不同尺寸及非连续输入的批量响应与单任务逐值一致。500 个纯 NCC 的串行逐任务提交为 73.0390 ms，集中批量为 20.4214 ms。全局单批因失去 CPU/GPU 重叠而达到 74.8585 ms，改为每 4 个任务一组并行处理后降至 44.7833 ms。

　　GPU 单点复核试验出现 0.000232 的分数差并回退至 55.5599 ms，已撤下。逐任务 GPU 直接评分虽保持评分完全一致，但回退至 89.9748 ms，同样未保留。可分离定点插值后 GPU 为 40.1986 ms、CPU 为 55.425 ms。复用搜索块常量检查并提前结束局部邻域扫描后，GPU 为 37.491 ms、CPU 为 52.0553 ms。新增 `Ncc.SameSizeMatch` 验证同尺寸响应逐值一致。Top-1 改用同顺序线性选择后，GPU 阶段测量为 36.6663 ms、CPU 为 51.7553 ms。每批 8 个任务复测为 41.1873 ms，仍保留每批 4 个。最终完整 CUDA Release 验收的 GPU 中位数为 39.9098 ms，报告采用该次结果，不挑选阶段较低值。

　　两种后端均未达到 20 ms 目标。符合批量条件的任务已完成集中传输及模板统计预计算，剩余主要工作在原算法不变的 CPU 候选筛选与亚像素精化。批量结果的单任务搜索时间包含组内 GPU 耗时的均摊值。

　　原始计时由性能测试写入 `temp/t10_benchmark500.csv` 和 `temp/t11_gpu_benchmark500.csv`。调试配置不参与 Release 指标判定。重复测量会受系统负载影响，报告使用本轮最终执行的数值，不挑选历史较低值。
