# MFC 测试优化文档

- 记录日期：2026-11-09。
- 当前状态：已形成 T16～T35 执行计划，正在按第 4 节顺序实施。
- 适用范围：MFC 单次匹配工作区、MFC 批量评估及界面内性能评估。核心匹配算法、公共接口和算法库性能优化不在本文档范围内。
- 执行方式：第 4 节为逐项修改与验收清单。完成一个条目的修改、回归和对应验收后才能勾选，未验证不得勾选。

## 1. 功能调整

1. 删除“框选模板”按钮及对应的模板框选模式，模板只通过单独加载图片指定。
2. 保留“设置 ROI”和“清除 ROI”，用于控制搜索范围。
3. 新增“复位”按钮，恢复当前搜索图和模板图刚加载完成时的单次匹配基准状态。
4. 复位只作用于单次匹配工作区，不隐式修改批量评估的目录、任务数或线程数。

## 2. 复位状态定义

1. 搜索图和模板图加载齐全后，在内存中保存原始图片、图片路径、搜索参数和后端设置。
2. 重新加载一对新图片后，更新基准状态，不得复位到上一对图片。
3. 复位时恢复基准图片、搜索参数和后端设置。
4. 清除后来设置的 ROI、临时框选、匹配结果、结果框、中心点和结果列表。
5. 清除旧状态提示并显示明确的复位状态。
6. 复位只恢复输入和配置，不自动执行搜索。复位后结果区为空，直到用户重新执行。
7. 没有完整的搜索图和模板图基准时，复位按钮不可用。

## 3. 优化问题核查

### 3.1 动态拉伸时分割线及控件错乱

- `applyLayout` 会重新计算分割线和控件的位置，动态布局计算已经存在。
- 布局结束后只显式调用页签的 `RedrawWindow`，没有统一强制重绘全部子控件和自绘区域。
- 判断：存在明确的重绘缺口，可能产生旧位置残留或分割线错乱。需用连续缩放回归确认，不把原因写成完全没有动态计算。

### 3.2 全屏或拉伸时图像窗口未更新

- `applyLayout` 已调整 `IDC_SEARCH_VIEW` 和 `IDC_TEMPLATE_VIEW` 的尺寸。
- 图像控件没有 `OnSize` 处理，也没有在尺寸变化后主动调用 `Invalidate`。
- `OnPaint` 会按最新客户区重新计算等比例显示区域，但只有收到重绘消息后才会执行。
- 判断：存在尺寸变化后的重绘缺口。图像等比例计算逻辑已存在，需验证控件实际尺寸和最终绘制尺寸是否同步更新。

### 3.3 ROI 矩形触碰窗口边界后无法生成

- 鼠标拖动时，`OnMouseMove` 会把坐标限制在图像显示矩形内。
- 鼠标释放时，`OnLButtonUp` 直接使用未限制的坐标调用 `updateSelection`。
- `pointToImage` 会拒绝显示矩形外的释放点，导致 `hasSelection_` 变为 false，最终不发送 ROI 更新通知。
- 判断：已定位为实际的边界处理缺陷。释放坐标应与拖动过程使用相同的边界限制规则。

### 3.4 页签选中项没有高亮

- 当前使用原生 `SysTabControl32`，没有 `TCS_OWNERDRAWFIXED` 或自定义选中项绘制。
- `OnDrawItem` 只处理按钮，页签完全依赖系统默认选中样式。
- 判断：已确认缺少明确的自定义高亮。页签切换逻辑与页面显隐测试已通过，本项只涉及选中状态辨识度。

### 3.5 执行参数摘要与实际配置不一致

- `IDC_EXECUTION_HINT` 在资源文件中固定显示“当前为固定角度、原始尺度搜索”，后续没有根据输入控件更新。
- `readConfig` 实际读取角度和尺度输入。既有自测截图中，角度已设为 -2～1°、尺度已设为 0.9～1.05，固定提示仍保持不变。
- 判断：提示与实际执行配置存在明确矛盾。应根据当前配置动态生成摘要，至少说明角度、尺度和 ROI 状态，复位时同步恢复基准摘要。

### 3.6 ROI 缺少持久数值与状态显示

- `OnImageSelectionChanged` 设置 ROI 后只显示“ROI 已设置”，界面没有持续显示 x、y、宽度和高度。
- 当前主要依靠临时红框辨认搜索范围，无法直接核对或精确输入 ROI 数值，也不利于复现参数试验。
- 判断：ROI 状态展示不完整。应提供可查看和编辑的 x、y、宽度及高度，并保证数值、红框和传入核心的 ROI 一致，清除及复位时同步清空。

### 3.7 单次搜索期间界面同步阻塞

- `OnExecute` 在界面线程直接调用 `LocatorWorkflow::runSingle`，搜索结束后才更新结果和状态。
- 当前没有忙碌状态、进度提示或取消入口。较大的角度和尺度组合会使窗口在搜索期间无法响应。
- 判断：单次长搜索存在响应性缺口。应在后台线程执行，通过界面线程消息统一更新结果，并在执行期间禁止重复搜索、重新加载和复位等冲突操作。

### 3.8 搜索失败后旧结果未失效

- 参数格式错误或核心返回错误时，`OnExecute` 在 `prepareResultList` 和 `searchView_.setResults` 之前返回。
- 上一次成功的结果列表、结果框和中心点可能继续保留，用户容易将其误认为本次失败配置产生的结果。
- 判断：结果与本次执行状态可能不一致。开始新搜索时应标记旧结果失效，失败时清空结果列表和叠加内容，状态栏保留明确错误。

### 3.9 单次搜索异常提示边界不完整

- `LocatorWorkflow::runSingle` 和 `OnExecute` 没有统一异常捕获，核心单次接口也只捕获部分参数及 CUDA 异常。
- OpenCV 异常、内存分配异常或其他标准异常可能绕过现有中文错误提示，无法保证转换为 `InternalError`。
- 判断：异常路径缺少界面保护。应在单次工作流和界面调用边界捕获并转换异常，保留可诊断信息，不修改核心匹配算法和公共接口。

### 3.10 参数错误定位与有效范围提示不足

- `readConfig` 返回失败后只提示“参数格式无效”，核心的 `InvalidConfig` 也只映射为“配置参数无效”。
- 提示无法指出具体字段，部分输入项也未说明有效范围，例如步进大于 0、金字塔和 Top-N 至少为 1、分数为 0～100、去重半径大于或等于 0。
- 判断：参数试验的排错信息不足。应增加字段级校验、错误定位和有效范围说明，使用户能直接找到需要修正的输入项。

### 3.11 多目标结果列表与叠加显示缺少联动

- 结果列表没有选择变化通知，图像控件使用相同样式绘制全部结果，无法通过列表定位对应结果框。
- 每个结果的文字标签都从中心点向右下绘制，多目标或靠近边缘时可能重叠或被裁切。
- 判断：Top-N 结果审查能力不足。应增加结果序号和列表选中高亮，并处理标签防重叠及图像边界，保证列表行与叠加结果可对应。

### 3.12 大图 ROI 框选缺少缩放和平移

- 图像控件只按客户区整体缩放显示，`pointToImage` 直接按显示矩形换算原图坐标，没有局部放大和平移能力。
- 大图缩小显示时，一次鼠标移动可能对应多个原图像素，难以进行精确的 ROI 框选。
- 判断：大图操作精度不足。应增加缩放、平移和当前像素坐标提示，并保证不同显示比例下的 ROI 原图坐标一致。

### 3.13 非灰度图片会被静默转换

- `loadGrayImage` 使用 `cv::IMREAD_GRAYSCALE` 读取图片，彩色图片会被转换为 8 位单通道后通过类型检查。
- 界面提示要求选择有效的 8 位灰度 BMP，但实际加载过程没有告知用户发生了灰度转换。
- 判断：输入格式行为与提示不一致。按当前需求应拒绝非 8 位单通道图片并说明原始格式，读取失败时不得替换当前有效图片。

### 3.14 批量执行配置来源不可见

- `OnBatchRun` 通过 `readConfig` 读取搜索参数页，并继续沿用单次工作区的 `useRoi_` 和 `roi_`。
- 批量页只显示目录、任务数和线程数，用户无法直接核对本次批量使用的角度、尺度、金字塔、亚像素、阈值、Top-N、去重及 ROI。
- 判断：批量执行配置不透明。应显示完整配置摘要，并明确选择批量使用完整图像还是指定的 ROI，避免单次工作区的 ROI 在无提示的情况下影响全部任务。

### 3.15 批量执行阻塞且旧统计未失效

- `OnBatchRun` 在界面线程调用 `LocatorWorkflow::runBatch`，`CWaitCursor` 只改变鼠标指针，不能保持窗口响应。
- 当前没有任务进度和取消入口。参数错误、目录读取失败或执行异常时，旧批量统计也不会自动失效。
- 判断：批量执行状态管理不完整。应在后台执行并显示已完成任务数，支持在任务边界取消，开始新批量及执行失败时清除或明确标记旧统计。

### 3.16 批量结果审查与导出不足

- 当前只把失败或无匹配任务加入左侧列表，成功任务的坐标、角度、尺度和分数无法在界面检查。
- 成功与失败统计把无匹配归入失败，界面没有结果导出功能，不利于比较不同参数和处理异常任务。
- 判断：批量正确性审查能力不足。应提供全部、失败和无匹配任务筛选，分别统计执行成功、无匹配及执行错误，并支持导出任务结果和统计。

### 3.17 界面性能评估缺少固定基准过程

- `OnBatchRun` 每次只调用一次 `runBatch`，没有预热和重复轮次，首轮 CUDA 初始化会直接影响结果。
- 控制台固定基准采用预热 5 轮、记录 50 轮。500 个任务循环使用 197 对独立图像，这一数据组成在批量页没有说明。
- 判断：界面测量结果不能直接替代正式性能基准。应提供固定基准模式，记录逐轮耗时和整体中位数，单独说明首轮初始化、任务组成及计时边界，并支持导出原始数据。

### 3.18 批量目录选择与数据数量提示不准确

- “选择目录”实际使用 `CFileDialog` 选择文件，再取文件父目录，操作方式与按钮名称不一致。
- 批量说明固定写为 197 对真实数据，其他 Thick 数据目录下无法反映实际配对数。
- 判断：目录交互和数据口径提示不准确。应改用目录选择对话框，并根据扫描结果显示配对数及任务循环复用规则。

## 4. 逐项修改与验收清单

- [x] 1. 功能调整：删除“框选模板”按钮及相关状态和鼠标路径，不得再进入模板框选模式。保留加载模板、设置 ROI 和清除 ROI。
- [x] 2. 复位功能：加载图片后修改参数、设置 ROI 并执行多次搜索，复位应恢复基准图片、参数和后端，清除 ROI、结果及叠加内容，不自动搜索，也不修改批量目录、任务数或线程数。重新加载另一对图片后，应恢复新基准。
- [x] 3. 动态布局（3.1）：连续拖动窗口四边及四角，交替最大化、还原和最小化，分割线、按钮、输入框及结果列表不得残留、重叠或尺寸停滞。
- [x] 4. 图像窗口（3.2）：连续缩放、最大化和还原后，搜索图及模板的控件尺寸和最终绘制尺寸应同步更新，保持原始比例和方向，不得残留旧图像。
- [x] 5. ROI 边界（3.3）：从图像内部向四个边界及边界外拖动并释放，均应生成边界内有效的 ROI，坐标不得超出原图。
- [x] 6. 页签高亮（3.4）：切换“搜索参数”和“批量评估”时，选中项应有清晰高亮，页签状态与下方页面一致。
- [x] 7. 参数摘要（3.5）：设置多组非默认角度、尺度和 ROI 后，执行摘要应与实际配置一致，复位后恢复基准摘要。
- [x] 8. ROI 数值状态（3.6）：通过鼠标和数值分别设置、修改及清除 ROI，数值、红框和核心配置应一致，复位后不得保留 ROI。
- [x] 9. 单次执行状态（3.7）：较长的单次搜索期间仍可缩放窗口和切换页签，重复搜索、重新加载和复位等冲突操作应受控。完成后只更新一次结果，且结果对应执行时的输入。
- [x] 10. 单次失败状态（3.8）：成功搜索后分别触发参数格式错误和核心执行错误，旧结果列表、结果框及中心点不得继续显示为本次结果。
- [x] 11. 单次异常边界（3.9）：在测试侧模拟 OpenCV 异常和其他标准异常，程序不得异常退出，应显示明确中文错误，旧结果不得保留为本次结果。
- [x] 12. 参数诊断（3.10）：分别输入零或反向步进、反向范围、非正尺度、零金字塔层数、越界分数、零 Top-N 和负去重半径，错误提示应指出具体字段及有效范围。
- [ ] 13. 多目标联动（3.11）：返回多个 Top-N 结果后逐行选择，图像应高亮对应结果，标签不得相互遮挡或超出图像控件。
- [ ] 14. 大图 ROI 操作（3.12）：对大图进行多档缩放和平移后框选 ROI，核对原图坐标、图像比例和方向，复位后恢复基准显示及空 ROI 状态。
- [ ] 15. 图片格式（3.13）：分别加载 8 位灰度图、24 位彩色图和损坏图片。彩色及损坏图片应得到明确错误，加载失败不得替换当前有效图片。
- [ ] 16. 批量配置摘要（3.14）：修改搜索参数和单次 ROI 后，批量页应准确显示实际生效配置。未明确启用 ROI 时，全部批量任务应使用完整图像。
- [ ] 17. 批量执行状态（3.15）：长批量运行期间窗口保持响应，进度与已完成任务数一致。取消后不得继续启动新任务，失败或重新开始时旧统计不得冒充本次结果。
- [ ] 18. 批量结果与导出（3.16）：构造成功、无匹配和执行错误任务，筛选及分类统计应正确。导出文件中的任务编号、匹配字段和计时应与界面及核心结果一致。
- [ ] 19. 界面固定基准（3.17）：按预热 5 轮、记录 50 轮执行 500 任务，界面明确说明 197 对独立图像的循环复用关系，输出整体中位数、逐轮原始耗时及首轮初始化信息。
- [ ] 20. 批量目录（3.18）：不选择具体文件即可指定目录，界面显示的配对数应与实际扫描结果一致，任务数大于配对数时应说明循环复用规则。
- [ ] 21. 回归验收：每完成一个条目，根据改动范围运行核心回归、双后端回归和 MFC 无界面自测，不得影响既有匹配功能。未运行或未通过的条目不得勾选。
