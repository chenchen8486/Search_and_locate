## 4. 500 任务性能

　　固定口径为 500 个任务、197 对独立图像、Release x64、20 线程、完整图、角度 0、尺度 1、金字塔 1、亚像素 8、Top-N 1。预热 5 轮、记录 50 轮。GPU 计时包含数据传输、同步和资源释放。

| 后端 | 整体中位数 | 单任务预处理均值 | 单任务搜索均值 | 单任务整体均值 | 单任务 P99 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CPU | 141.835 ms | 0.0118528 ms | 4.37965 ms | 4.39501 ms | 22.8369 ms |
| GPU | 187.489 ms | 0.00808356 ms | 6.82011 ms | 6.82973 ms | 15.6688 ms |

　　两种后端均未达到 20 ms 目标。GPU 的双精度初版中位数为 1133 ms，改为两遍 FP32 计算后明显降低，但最终测量仍慢于同机 CPU。小图的亚像素精化和每任务调度仍有较大 CPU 开销，不能把使用 CUDA 内核直接写成整体性能优于 CPU。

　　原始计时由性能测试写入 `temp/t10_benchmark500.csv` 和 `temp/t11_gpu_benchmark500.csv`。调试配置的 GPU 最新中位数为 2033.08 ms，只用于调试，不参与 Release 指标判定。

## 5. MFC 验收记录

- 已有界面检查覆盖图像和模板加载、大图框选模板、ROI、单次结果、结果框、中心点和后端选择。
- `MfcWorkflow.SingleSearch` 验证共享单次调用、结果坐标和非负计时。
- `MfcWorkflow.BatchTiming` 验证 197 对真实数据的共享批量调用。
- Release 无界面自测中，CPU 单次整体 1.7894 ms、197 对批量 68.7829 ms。GPU 单次整体 129.584 ms、197 对批量 79.8314 ms。GPU 单次包含首次 CUDA 初始化。
- Debug 无界面自测中，CPU 单次整体 6.1823 ms、197 对批量 461.786 ms。GPU 单次整体 192.608 ms、197 对批量 834.49 ms。
- 两种配置的自测均逐对比较 CPU/GPU 的中心、角度、尺度和分数，退出码为 0。
